# StudyStack

Djangoで作成した学習記録アプリです。
ユーザーごとに学習内容を登録・編集・削除できます。

## 主な機能

- ユーザー登録
- ログイン / ログアウト
- 学習記録の登録
- 学習記録の一覧表示
- 学習記録の編集
- 学習記録の削除
- ユーザーごとのデータ分離
- 入力バリデーション

## 使用技術

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## 実装で学んだこと

### DjangoのCRUD

Create / Read / Update / Delete の基本的な流れを実装しました。

特にUpdateでは、
URLから取得した `study_id` とログイン中の `request.user` を利用して、
対象ユーザーの学習記録だけを取得・更新する仕組みを学びました。

### ModelFormとバリデーション

`StudyForm` をCreateとUpdateの両方で使用し、
フォーム側に入力チェックの責務を持たせました。

独自バリデーションとして、

- 空白のみの入力を禁止
- 3文字以下の入力を禁止

を実装しました。

### 認証とユーザーごとのデータ管理

`@login_required` を使用して、
ログインしているユーザーだけがダッシュボードへアクセスできるようにしました。

また、

`user=request.user`

を条件として使用することで、
他ユーザーの学習記録を編集・削除できないようにしました。

### URL / View / Template の役割

DjangoではHTMLファイルへ直接遷移するのではなく、

URL → View → Template

という流れで画面を表示することを学びました。

### POST処理

登録・削除・ログアウトなど、
状態を変更する処理ではPOSTを使用しました。

削除時にはJavaScriptの `confirm()` を使用し、
誤操作防止の確認ダイアログも追加しました。
